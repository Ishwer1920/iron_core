Check your product's authenticity

Enter the unique verification code printed on your IronCore Pharma pack. Each genuine code works only once.

How it works

  1. Find the code — look for the scratch/printed verification code on the product label or box.
  2. Enter it above — type the code exactly as printed and tap Verify.
  3. Read the result — a genuine, unused code shows Verified. A code that's unknown or already used is flagged.

Because each code is single-use, a code that comes back as already used on a sealed pack may indicate a counterfeit. When in doubt, contact us.
